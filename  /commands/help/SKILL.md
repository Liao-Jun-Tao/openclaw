# Help Command

Get help with OpenClaw.

## General Help

```bash
bash command:"openclaw help"
bash command:"openclaw --help"
```

## Command Help

```bash
/help commit        # Help for specific command
/help model
/help config
```

## Tool Help

```bash
/help bash          # Help for bash tool
/help read
/help edit
/help grep
```

## Interactive Help

```bash
# Open help browser
/help --browser

# Search help
/help --search "git commit"
```

## Common Topics

| Topic              | Description                 |
| ------------------ | --------------------------- |
| `/help commands`   | List all available commands |
| `/help tools`      | List all available tools    |
| `/help skills`     | List all available skills   |
| `/help config`     | Configuration guide         |
| `/help quickstart` | Quick start guide           |

## Examples

### Learning a New Command

```
/help mcp
# Shows: Usage, options, examples, troubleshooting
```

### Finding a Tool

```
/help tools
# Shows all available tools with descriptions
```

### Configuration Help

```
/help config set model
# Shows how to set model configuration
```
