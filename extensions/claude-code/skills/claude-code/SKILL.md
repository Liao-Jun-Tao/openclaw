This skill provides Claude Code CLI compatible tools and commands for OpenClaw.

## Tools

| Tool | Description |
|------|-------------|
| `bash` | Execute shell commands |
| `read` | Read file contents |
| `edit` | Edit files in place |
| `glob` | Find files by pattern |
| `grep` | Search file contents |

## Commands

| Command | Description |
|---------|-------------|
| `/commit` | Create git commits |
| `/review` | Code review |
| `/diff` | View differences |
| `/branch` | Manage branches |
| `/session` | Session management |
| `/compact` | Compact context |
| `/model` | Switch models |
| `/config` | Configuration |
| `/theme` | Theme settings |
| `/init` | Initialize project |
| `/mcp` | MCP servers |
| `/clear` | Clear conversation |
| `/rewind` | Rewind messages |
| `/doctor` | Diagnostics |
| `/resume` | Resume session |
| `/help` | Get help |
| `/cost` | Usage costs |
| `/usage` | Usage stats |
| `/plan` | Planning mode |
| `/hooks` | Workflow hooks |
| `/status` | System status |

Use `/help <command>` for detailed information about any command.
